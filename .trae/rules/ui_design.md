# UI 设计规范

## Theme.qml 设计系统（强制遵守）
- 所有UI组件必须使用Theme.xxx引用样式令牌
- 禁止硬编码颜色、字体、间距、圆角、动画时长
- 新增组件必须复用现有样式令牌，如需新增必须先在Theme.qml中定义

## 配色系统
- 深靛蓝背景：#0D0E15 → #1C1F30
- 粉红强调色：#FF4A70
- 紫色辅助：#8B5CF6
- 类别配色：10色循环数组classColors

## 字体系统
- UI字体：Segoe UI / Microsoft YaHei
- 等宽字体：Cascadia Code / Consolas
- 字号通过Theme.fontSizeXxx引用

## 组件一致性
- 按钮样式统一使用Theme定义的圆角、内边距、悬停效果
- 输入框样式统一，列表项高度间距统一，对话框风格统一

## 交互反馈规范
- 所有操作必须有视觉反馈：成功（绿色提示）、失败（红色提示+解决方案）、加载中（旋转动画或进度条）
- 耗时操作（>500ms）必须显示加载提示，禁止无反馈阻塞UI
- 按钮点击后立即响应（禁用态或loading态），防止重复提交
- 异步操作完成后通过Toast或状态栏通知用户结果

## 危险操作防护
- 不可逆操作（删除项目、删除快照、停止训练）必须二次确认弹窗
- 确认弹窗默认焦点在"取消"按钮上，防止误操作
- 删除操作弹窗需明确说明影响范围（如"将删除3个数据集及其所有样本"）
- 批量操作前必须预览影响范围

## 错误提示规范
- 错误提示必须包含解决方案或建议操作，禁止仅显示错误代码
- 格式：问题说明 + 原因分析 + 建议操作（如"训练启动失败：GPU内存不足，建议减小batch_size或切换到CPU模式"）
- IPC通信失败时提示用户检查Python后端状态
- 文件操作失败时提示用户检查文件权限和磁盘空间

## 加载状态规范
- 页面首次加载使用骨架屏或占位符，避免空白闪烁
- 列表加载使用下拉刷新+底部加载指示器
- 图片加载使用缩略图占位+渐入动画
- 长时间任务（训练/导出）使用进度条+百分比+预估剩余时间
