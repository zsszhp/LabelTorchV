# 02 安装与使用

## 安装方式

标炬提供两种获取方式：**绿色包（推荐）** 与 **源码构建**。

### 方式一：绿色包（解压即用）

绿色包无需安装 Python / Qt / conda，适合最终用户。

1. 获取压缩包 `LabelTorch-Green-v0.2.0.zip`
2. 解压到任意目录（路径建议**不含中文、空格与特殊符号**）
3. 双击 `start_LabelTorchV.bat` 启动

也可以直接运行 `LabelTorchV.exe`，但推荐使用启动脚本——它会先配置内嵌 Python 的搜索路径。

绿色包目录结构：

```
LabelTorch-Green-v0.2.0/
├── LabelTorchV.exe        # 主程序
├── start_LabelTorchV.bat  # 启动脚本（推荐入口）
├── LabelTorch\            # QML 模块
├── python\                # 内嵌 Python 运行时
├── backend\               # Python 后端（训练/推理/导出服务）
└── *.dll                  # Qt 运行库
```

注意事项：

- 训练 GPU 场景需 NVIDIA 驱动；包内默认内嵌 CPU 版 PyTorch，GPU 版请替换 `python\torch`
- 项目数据保存在用户数据目录（AppData），**删除绿色包不会清除已有项目**
- 可在「设置」中指定外部 Python 路径，默认使用内嵌 `python\python.exe`

### 方式二：源码构建（开发环境）

前置条件见 [01-简介与系统要求](01-简介与系统要求.md)。

```powershell
# 1. 配置
cmake --preset msvc2022-release

# 2. 构建
cmake --build --preset msvc2022-release

# 3. 测试
ctest --preset msvc2022-release
```

构建输出目录：`out/build/msvc2022-release/`。

可用预设：`msvc2022-debug`、`msvc2022-release`、`x64-debug`、`x64-release`、`mingw-debug`、`mingw-release`。

Python 后端依赖安装：

```powershell
cd backend
pip install -r requirements.txt
```

关键依赖：`ultralytics`、`onnxruntime`、`opencv-python`、`Pillow`、`numpy`。异常检测功能需要额外安装 `anomalib`（可选，未安装时该适配器自动跳过注册）。

## 首次启动

1. 启动后进入**项目**页面
2. 点击「新建项目」，选择项目路径与任务类型
3. 状态栏确认 **Python 后端** 已连接（绿色指示）；未连接时点击「重连」

> 项目路径建议使用纯英文、无空格路径。路径含中文或空格时会有警告提示（多数场景可用，但可能影响训练/导出）。

## 设置项

| 设置项 | 说明 |
|--------|------|
| Python 路径 | 默认内嵌 Python；指定外部路径后需重启后端生效 |
| 日志级别 | trace / debug / info / warning / error，立即生效 |
| 窗口状态 | 自动记忆窗口大小与位置 |

## 数据存储位置

| 内容 | 位置 |
|------|------|
| 应用数据库 | `AppData/labeltorch/labeltorch.db` |
| 项目数据 | 项目根目录下的 `datasets/ snapshots/ models/ runs/ exports/ logs/` 等 |
| 缩略图缓存 | 项目目录 `cache/thumbnails` |
| 运行日志 | 项目目录 `logs/` |

## 卸载

1. 关闭标炬
2. 删除绿色包目录即可
3. 如需彻底清除数据，另行删除 `AppData/labeltorch/` 与各项目根目录

> 注意：项目数据与软件目录相互独立，卸载软件不会自动删除项目数据。删除项目请在软件内操作（会二次确认并列明连带删除项）。
