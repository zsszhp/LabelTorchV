# 01 简介与系统要求

## 产品简介

**标炬（LabelTorch）** 是面向工业缺陷检测场景的本地离线视觉数据治理与模型闭环平台。

核心工作流：**导入数据集（图片 + YOLO txt 标签）→ 数据冻结版 → 训练 → 测试评估 → 智能辅助 → 导出模型（pt/onnx）**。

支持的任务类型：

| 任务类型 | 说明 |
|----------|------|
| detect | 目标检测（水平框） |
| obb | 旋转框检测 |
| classify | 图像分类 |
| anomaly | 异常检测 |

## 主要能力

- **项目管理**：创建/打开项目，任务类型切换，最近项目列表
- **数据导入**：YOLO txt、COCO json、无标签图片三种形态，自动扫描匹配与校验
- **数据质量**：重复图检出、train/val 跨划分泄漏检测、坏标签定位
- **类别体系**：类别管理、类别映射（重排/合并/拆分），映射历史可追溯
- **标注**：HBB/OBB/分类标注，修订追踪（撤销/审计）
- **数据冻结版**：训练数据快照，按内容哈希冻结，训练前校验完整性
- **训练工作台**：Ultralytics YOLO 系列（v5/v8/v8-obb/v8-cls/v10/v11），参数配置模板，实时曲线
- **测试评估**：PR 曲线、混淆矩阵、逐类指标、部署阈值推荐、产线 KPI Go/No-Go
- **智能辅助**：辅助标注审核、难例挖掘（低置信/误检/漏检/难例队列）、异常检测、视频推理
- **模型导出**：pt/onnx 导出，产物验证，交付目录生成
- **审计追溯**：删除、导入、训练启停、导出等关键操作全部入审计日志

## 系统要求

### 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 |
| 处理器 | x64 四核 | x64 八核及以上 |
| 内存 | 8 GB | 16 GB 及以上 |
| 显卡 | 无（CPU 训练可用） | NVIDIA GPU，显存 ≥ 6 GB（RTX 30/40/50 系列） |
| 磁盘空间 | 20 GB（软件 + 依赖） | 50 GB 及以上（大数据集与模型产出） |
| 显示器 | 1366×768 | 1920×1080 及以上 |

说明：

- **CPU-only 路径可用**，但训练速度显著慢于 GPU，建议仅用于小数据集验证。
- GPU 训练需 NVIDIA 驱动支持 CUDA 12.1。
- 数据集与模型文件会占用较多磁盘，建议项目目录放在剩余空间充足的盘符。

### 软件依赖（开发构建环境）

| 组件 | 版本 |
|------|------|
| Qt | 6.11+（MSVC 2022 64-bit） |
| Visual Studio | 2022（MSVC x64） |
| CMake | 3.22+ |
| Ninja | 任意近期版本 |
| Python | 3.11+（conda 环境 `labeltorch`） |
| Python 依赖 | ultralytics、onnxruntime、opencv-python、Pillow、numpy；可选 anomalib |

日常使用者一般不需要自行搭建上述环境，直接使用安装包即可。安装步骤见 [02-安装与使用](02-安装与使用.md)。

## 界面概览

启动后主界面分为三部分：

1. **左侧导航栏**：8 个主页面入口（项目、数据集、检查、标注、训练、测试、智能辅助、导出），底部显示 GPU 状态与 Python 后端连接状态
2. **中间内容区**：当前页面工作区
3. **底部日志面板**：可折叠，显示后端错误与任务日志

导航按分组排列：

| 分组 | 页面 |
|------|------|
| 数据 | 项目、数据集、检查、标注 |
| 训练评估 | 训练、测试 |
| 交付 | 智能辅助、导出 |

部分页面提供不占导航的**子入口**（进入后标题栏显示「返回」）：数据导入向导、类别映射、类别体系、数据冻结版、模型中心、指标对比。
