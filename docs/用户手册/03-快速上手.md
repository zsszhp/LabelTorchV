# 03 快速上手

本章带你完整走通主工作流：**建项目 → 导入 → 数据冻结版 → 训练 → 导出**。全程约 10 分钟（不含训练时长）。

## 第 1 步：创建项目

1. 启动标炬，进入「**项目**」页面
2. 点击「新建项目」
3. 填写：
   - **项目名称**：如 `产线A划痕检测`
   - **项目路径**：建议纯英文无空格，如 `D:\projects\scratch-a`
   - **任务类型**：目标检测（detect）/ 旋转框（obb）/ 分类（classify）/ 异常检测（anomaly）
4. 确认创建，然后点击项目卡片进入

> 类别体系可在项目页「类别管理」中维护（界面文案为**类别体系**）。导入数据时会自动提取类别并同步。

## 第 2 步：导入数据集

1. 进入「**数据集**」页面，点击「导入向导」
2. 选择数据形态：
   - **图片 + YOLO txt 标签**：分别指定图片目录与标签目录
   - **COCO json**：指定图片目录与标注 JSON
   - **仅图片**：先导入图片，后续用辅助标注补标签
3. 系统自动扫描并显示匹配结果：
   - 已匹配（图片 + 标签一一对应）
   - 标签无效（图片保留，标签问题见检查页）
   - 未匹配图片（无标签图片）
4. 如源标签的类别顺序与项目类别体系不一致，进入第 2 步「**类别映射**」建立映射规则
5. 确认导入

导入完成后可在数据集页查看：

- 样本总数、已标注/未标注统计
- 类别分布
- 缩略图网格浏览

**数据质量检查**：进入「**检查**」页面，可检出重复图片、train/val 跨划分泄漏、坏标签等问题样本。建议导入后先跑一次检查。

## 第 3 步：创建数据冻结版

数据冻结版（内部称快照）是训练数据的**不可变副本**，按内容哈希冻结。训练必须基于数据冻结版，而不是数据集实时状态——这样即使后续改了标注，历史训练仍可追溯。

1. 进入「**训练**」页面
2. 在「数据冻结版」子区点击「创建数据冻结版」
3. 选择数据集与 train/val 划分比例（默认 8:2）
4. 确认创建

创建时系统会记录每个样本的内容哈希。训练启动前自动校验哈希：

- 一致 → 使用冻结的标签开始训练
- 不一致（样本被修改过）→ 拒绝训练或提示物化冻结副本

> 也可以从训练页的「数据冻结版」入口进入独立管理页，查看历史冻结版清单。

## 第 4 步：训练

1. 在「**训练**」页面选择数据冻结版
2. 配置训练参数：
   - **模型家族**：yolov8 / yolov8-obb / yolov8-cls / yolov5 / yolov10 / yolov11
   - **epochs / batch / imgsz** 等基础参数
   - 数据增强配置
3. 可用「保存配置模板」把常用参数存为模板，下次一键加载
4. 点击「开始训练」

训练过程中：

- 状态栏与任务面板显示运行状态
- 实时曲线显示 loss / mAP50 / mAP50-95 / precision / recall
- 日志面板输出训练日志
- 可随时「停止训练」

**训练失败怎么办**：失败的运行会附带日志尾部与结构化诊断，并提供「一键降 batch/imgsz」建议按钮。详见 [05-故障排查](05-故障排查.md)。

训练成功后自动生成模型版本，可在导出页的「模型中心」查看血缘（模型 → 训练运行 → 数据冻结版）。

## 第 5 步：测试评估（建议）

1. 进入「**测试**」页面
2. 选择模型版本与评估数据（数据冻结版）
3. 运行评估，查看：
   - PR 曲线、混淆矩阵
   - 逐类 AP/P/R（哪类漏检最多）
   - **部署阈值推荐**：推荐 conf 阈值、万件漏检/超检预估
   - 产线 KPI 的 **Go / No-Go** 结论

## 第 6 步：导出模型

1. 进入「**导出**」页面
2. 在「模型版本」侧栏选择要导出的版本
3. 选择格式：
   - **pt**：PyTorch 权重，便于后续继续训练
   - **onnx**：部署格式，可在导出配置面板调整 opset / 动态 batch 等
4. 点击「导出」

导出流程：`导出 → 验证 → 成功/失败`

- 导出完成后自动进入**验证**（ONNX Runtime / TorchScript 校验）
- 验证失败的产物状态为 `failed`，**不可**「标记生产」
- 验证通过后生成**交付目录**：模型文件 + `classes.yaml` + `thresholds.json` + `warmup.py` + 推理样例

交付目录可直接交给部署侧使用。

## 进阶：智能辅助闭环

| 能力 | 入口 | 用途 |
|------|------|------|
| 辅助标注 | 智能辅助 | 用模型推理新图，审核候选框，确认后回写 YOLO txt |
| 难例挖掘 | 智能辅助 | 低置信/误检/漏检/难例队列，优先审核，重启不丢 |
| 异常检测 | 智能辅助 | 单图/批量异常热力图 |
| 视频推理 | 智能辅助 | 视频抽帧推理 |

辅助标注确认的结果可一键「用本批数据再训练」，形成数据→模型闭环。
