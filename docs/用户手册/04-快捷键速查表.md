# 04 快捷键速查表

## 全局快捷键

| 快捷键 | 作用 |
|--------|------|
| `F1` | 打开使用帮助 |
| `?`（Shift + /） | 打开快捷键卡片 |
| `Ctrl+1` ~ `Ctrl+8` | 切换主导航页面（项目/数据集/检查/标注/训练/测试/智能辅助/导出） |
| `Esc` | 关闭弹窗 / 取消绘制 |

按 `Ctrl+数字` 对应的页面顺序：

| 快捷键 | 页面 |
|--------|------|
| `Ctrl+1` | 项目 |
| `Ctrl+2` | 数据集 |
| `Ctrl+3` | 检查 |
| `Ctrl+4` | 标注 |
| `Ctrl+5` | 训练 |
| `Ctrl+6` | 测试 |
| `Ctrl+7` | 智能辅助 |
| `Ctrl+8` | 导出 |

## 标注页快捷键

标注快捷键由画布层处理，在标注页内直接按键即可（无需先点画布以外区域）。

### 编辑操作

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+S` | 保存当前标注 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+A` | 全选标注 |
| `Ctrl+C` | 复制选中标注 |
| `Ctrl+V` | 粘贴 |
| `Ctrl+D` | 复制选中标注 |
| `Delete` | 删除选中标注 |
| `Backspace` | 删除选中标注（绘制多边形时删除最后一个顶点） |
| `Esc` | 取消绘制 / 退出绘制模式 |

### 绘制模式

| 快捷键 | 作用 |
|--------|------|
| `W` / `R` | 矩形框（HBB）绘制模式 |
| `O` | 旋转框（OBB）绘制模式 |
| `P` | 多边形绘制模式 |
| `Enter` / `Return` | 结束多边形绘制（顶点数 ≥ 3 时） |

### 视图与导航

| 快捷键 | 作用 |
|--------|------|
| `Space`（按住） | 拖动画布（手型平移） |
| `F` | 适应窗口（fit to view） |
| `A` | 上一张图片 |
| `D` | 下一张图片 |

### 标注微调

| 快捷键 | 作用 |
|--------|------|
| `1` ~ `9` | 切换到第 N 个类别 |
| `[` / `]` | 切换上一个 / 下一个类别 |
| `方向键` | 移动选中标注（每次 5 像素） |
| `Z` / `X` / `C` / `V` | 旋转选中的旋转框（-1° / -0.1° / +0.1° / +1°） |

> 注意：`A` / `D` / `Z` / `X` / `C` / `V` 在 `Ctrl` 组合下是编辑操作（全选/复制/粘贴/撤销/重做等），单独按下才是导航与旋转操作。

## 鼠标操作

| 操作 | 作用 |
|------|------|
| 左键拖拽 | 绘制标注框 / 选中与调整 |
| 滚轮 | 缩放画布 |
| 按住 `Space` + 左键拖拽 | 平移画布 |

## 使用提示

- 按 `F1` 随时打开使用帮助，按 `?` 打开快捷键卡片
- 快捷键卡片在应用内与本表内容一致，可对照使用
