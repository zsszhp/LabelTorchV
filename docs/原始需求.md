原始需求
痛点：我是做工业缺陷检测的，现在要训练 yolo 模型，我目前的模式是，用x-anything，labelme，labelimg 标注好导出标签（可能需要转化格式什么的），分为训练集、测试集，然后再用ultralytics 源码来修改配置参数，很麻烦而且容易出错

解决方案：我自己写一个标注软件

1.从 MVP 开始，MVP 先不用标注功能（拉框、画标签等），只需要实现导入数据集（图片、标签等），设置训练参数（img\_size、batch、epochs 、早停等），能导出模型（ pt或者onnx模型），注意好MVP的边界，只保留导入数据集（图片和txt标签）、训练、导出模型功能，先不要其他更多的乱七八糟的的功能；MVP先发布一个release版本，绿色安装版，把各种环境什么的一起打包，使得用户下载解压就能够直接导入项目开始训练。我现在的项目代码可能有点乱了（但是都可以舍弃），你先git保存一下，之后再看一下是否有能复用的代码，捉紧搞一套MVP出来，之后每个版本规划好，代码管理好，用上tag等方式，每个版本都得发布一个release

2.我想要的有很多的功能，后续的版本再慢慢加

比如v1版本，我要把标注功能加进去；v2版本增加审核查看的功能等等（这里是一个举例，不是实际的版本规划）

3.我主要是在 windows 平台使用，用 nividia 显卡训练，当然后续可能会考虑兼容 ubuntu
（实现windows稳定之后）



4.要能够兼容多个yolo版本，可以选择是用 yolov5 还是 yolov8 还是 yolov8\_obb 、v10、v11 等模型训练，因为我有时候会选择 v8，有时候会 v5 或者 v8obb



5.要能做增量训练，我新增图片的时候，需要能够选择上一版的模型进行辅助标注，我再检查确认标注是否正确
，比如我已经训练了第一版，我第二版的时候要用第一版来辅助标注增加更多的图片，并且模型权重能选择第一版的模型或者是选择官方的模型从头训练



6.我要把所有的依赖环境等都打包进软件里面，用户解压、安装即用，不用再很麻烦的去配置各种环境（哪怕因此造成软件包过大也无所谓）

7.后续版本的一些想法
增加标注功能：矩形框标注、旋转矩形标注、多边形标注
用户友好型，界面美观，用户操作逻辑顺畅
增加分类模型、异常检测模型的标注、训练


8.得兼容不同的显卡，如30系列、40、50系列的显卡都得兼容


9.有哪些开源的项目开源参考，先 clone 下来到 reference 文件夹，x-anything，labelme，labelimg等，还有我没考虑到的都得搜索完善，如何clone下来到references文件夹


10.稳定性最佳，不能出现任何的闪退、训练停止等等


11.要根据我的需求详细的规格各个版本的功能、职责，要边界清晰，并且确保每个版本都是可用的；规划多少个版本，每个版本实现什么样的功能等等这些，你得帮我做好规划，写好任务书，做好边界限制，这份蓝图、prd、规划我要给其他的 ai 来实现，要能够完整无偏差的实现出来
