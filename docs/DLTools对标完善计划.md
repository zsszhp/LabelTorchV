## 二、P0 标注页核心交互（实测差距最大）

DLTools 标注页 = 画布 + 左侧类别列表 + **右侧实例表格与文件列表**。LabelTorchV 画布与绘制已通（R/O/P/Del/Ctrl+Z 快捷键齐备），缺右侧信息面板。

### 1. 实例表格（标注页右侧新增）
- **DLTools 实测**：六列表格「类别 | X | Y | 宽度 | 高度 | 面积」；画框瞬间新增一行且坐标实时跟随鼠标；点表格行 → 画布选中该框。
- **现状**：右侧只有标签类别面板，画了几个框只能靠肉眼在画布上找。
- **方案**：右侧面板顶部加实例 `TableView`，模型直接绑定 `annotationModel`（rows = 当前样本标注）；行点击 → 设置画布选中项；画布选中变化 → 表格滚动高亮。坐标显示图像坐标系（与 Label 表 Region JSON 一致）。
- **验收**：画框 → 表格立现新行；点行 → 画布框高亮；改框 → 数值刷新。

### 2. 点框换类别（画布内联下拉）
- **DLTools 实测**：点中实例后，框下方弹出「类别色块 + 名称 ▼」下拉，直接换类别。
- **方案**：画布选中态下，在选中框上方渲染 ComboBox（用类别色做左侧色块），选项来自 taxonomyModel；切换即 `saveAnnotations` 落库。

### 3. Delete 删除选中实例（验证+补链）
- **DLTools 实测**：表格行选中 → Delete → 画布与 DB 同步删除。
- **现状**：快捷键提示有 Del，但「选中态」在画布/表格两侧是否联动未系统验证。
- **方案**：随 1/2 一并打通：画布或表格任一侧选中，Delete 均可删，撤销可回。

### 4. 文件列表完成勾（标注页）
- **DLTools 实测**：文件列表中已标注文件打绿色 ✓。
- **方案**：标注页样本列表（或数据集页缩略图角标）按 `label_path` 非空显示 ✓（Theme.success）。数据集页缩略图可复用 Tag 角标的位置规范，勾放右上、Tag 放左下或反之，避免重叠。

## 三、P1 检查页与全局反馈

### 5. 检查页类别筛选列表
- **DLTools 实测**：左侧「标签类别」区列出「未标注的图像 N」「色块 类别N = N」，多选即过滤中央网格（实例子集视图）。
- **现状**：检查页已有程度图像模式与徽章；无类别筛选。
- **方案**：左侧新增「标签类别」CollapsibleSection：未标注计数 + 各类别计数（`getClassDistribution` 已有）+ 复选过滤；与现有状态筛选叠加。

### 6. 筛选计数「已筛选的图像: N/M」
- **DLTools 实测**：筛选栏最右侧常显「已筛选的图像: 2/2」，任何筛选变化实时刷新。
- **方案**：数据集/检查页筛选栏右侧加 StatusTag（N = 过滤后，M = 总数），`applySampleFilters` 时更新。

### 7. 底部标注进度对齐
- **DLTools 实测**：底栏「标注进度」为进度条 + `N/M`。
- **现状**：底栏已有百分比进度条。
- **方案**：补 `N/M` 数字显示（低成本对齐）。

### 8. 隐藏标注开关（标注页）
- **DLTools 实测**：画布顶部「隐藏标注」Toggle，一键纯图查看。
- **方案**：画布工具栏加开关，置 `visible=false` 于标注渲染层（画布 controller 加 `setAnnotationsVisible(bool)`）。
- 亮度/对比度调节（DLTools 两个圆钮）列为 P2，标注场景价值低。

## 四、P1 类别管理补强（⚠️ 与并行会话协调）

并行会话正在做类别行内编辑（ClassStyleDialog，fbf20f7~60c15a5）。以下补强需与它对齐落地位置，避免双写：

### 9. 类别快捷键唯一性校验
- **DLTools 规则（字符串取证）**：「与其他已有Tag或标签类别的快捷键冲突」「标签类别快捷键不合法」。
- **方案**：`TagService.shortcutExists` 已做 Tag 间校验；类别侧在保存快捷键时同时查 `taxonomy_class_styles.shortcut` 与 `dataset_tags.shortcut`（同项目范围）。

### 10. 类别 modelIndex 唯一性
- **DLTools 规则**：「图库下已存在相同的模型Index」「模型Index必须大于0/小于列表数量」，冲突时提示交换。
- **方案**：类别样式编辑保存时校验 modelIndex 唯一；冲突时提示「与类别N交换」。

### 11. 类别颜色校验
- **DLTools 规则**：「标签类别不能使用#000000颜色」「与其他已有标签类别的颜色冲突」。
- **方案**：颜色选择器保存前拒绝纯黑与重复色。

## 五、P2 数据集管理与长期项

### 12. 数据集锁定/解锁
- **DLTools 规则**：「数据集已被锁定, 操作失败」「锁定/解锁数据库失败」；锁定后批量标注/打标被拒。
- **方案**：datasets 表加 `locked` 列（迁移 V5→V6）；数据集卡片右键/设置入口切换；写路径（打标/批量标注）检查锁。

### 13. 移动/复制图像到数据集
- **DLTools**：多选 → 移动/复制到同图库其它数据集（`UNIQUE(Path, DataSet_id)`）。
- **方案**：多选后右键菜单加「移动到…/复制到…」（数据集下拉选择）；后端 `moveSamples/copySamples`。

### 14. 匹配页·特征匹配（DLTools 独有，需立项评估）
- **DLTools**：选数据集 → 用良品图建特征库 → 对无标注图做漏检/过杀匹配（依赖 faiss/embedding）。
- **建议**：与 LabelTorchV 现有「智能辅助」（AssistPage）能力部分重叠，先评估复用 assistedLabelService + 后端 embedding 管线的成本，单独立项，不混入本计划迭代。

## 六、明确不照抄的项

| DLTools 做法 | LabelTorchV 决策 | 理由 |
|---|---|---|
| Tag 角标 = 纯色小方块（无文字） | 保留带名胶囊 | 自定义 Tag 无语义色，纯色块不可辨识；胶囊信息量大 |
| 批量打标 UI 即时变色、DB 延迟落库（实测 UI 变色后 SQLite 两次查询均未变） | 即时落库 + Toast 结果反馈 | 可靠性优先，避免「假成功」 |
| 搜索需回车触发 | 实时过滤 | 输入即所得 |

## 七、实施顺序与验收

1. **第一批（P0）**：实例表格 → 点框换类别 → Delete 链路 → 完成勾。全部在标注页一个文件族内，风险集中可控。
2. **第二批（P1）**：检查页类别筛选 → 筛选计数 → 底栏 N/M → 隐藏标注。
3. **第三批（P1）**：类别校验三件套（与并行会话对齐后做）。
4. **P2**：锁定/移动复制按需排期；匹配页单独立项。

**统一验收标准**：
- 交互链路实测通过（操作 → UI → DB 落库 → 重启后仍在）；
- 日志门禁：新增 0 个 QML TypeError/ReferenceError；
- ctest 全过（25+），TagService/新服务有单测覆盖；
- 每小目标一个 commit，推送 GitHub + Gitee。
