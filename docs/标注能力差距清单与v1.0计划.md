## 四、我方已有且领先 X-AnyLabeling 的能力

- 光标为中心的滚轮缩放（X 无）；空格/中键平移；Ctrl+A 全选
- 更深撤销栈（50 步 vs 10）；300ms 自动保存（防抖+切图冲刷+原子写）
- 连续绘制模式（画完保持 draw）；四种任务类型一键 E2E（训练/评估/导出全链路，X-AnyLabeling 无训练）
