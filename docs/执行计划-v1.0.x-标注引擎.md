## 一、目标与非目标

### 1.1 目标

标注能力达到可替代 labelme / x-anything 的实用水平，OBB 链路端到端贯通：

1. 多边形标注可绘制、顶点可编辑、可撤销、与 YOLO 格式双向闭环，训练可用。
2. 画布体验满足产线连续帧标注节奏：平滑缩放、右键菜单、复制上帧、大图不卡。
3. OBB 从标注 → 数据划分 → 训练 → 导出验证全链路无断点。
4. 辅助标注批量审核产品化，接通已有 `commitConfirmedLabels` / `retrainFromBatch`。
5. 快捷键可配置、标注统计可见，单帧标注效率可量化。

### 1.2 非目标

- 不做增量训练、主动学习队列、错误分析报告（归 v1.1.x）。
- 不做工业元数据、批次追溯、IATF 交付（归 v2.0.x）。
- 不做分割掩码（mask）标注与 SAM 自动分割接入。
- 不做多人协同标注与服务端标注。
- 不更换绘图内核（继续基于 `AnnotCanvasItem` + QPainter）。
- 不做视频抽帧标注工具链（`VideoInferencePage` 仅保持现状可用）。

### 2.4 源码核实后对旧计划的修正（开工时按此执行）

1. 标签坐标写出是 **6 位小数**（旧文写 5 位有误）；验收「坐标误差 < 1e-4」仍成立，因 6 位小数量化误差 5e-7。
2. `parsePolygonLine` 现状会拒 3/4 点多边形，且 `detectFormat` 会把 7/9 token 的多边形误判为未知/HBB——A1 第一优先修。
3. 剪贴板（复制/粘贴/原地复制）丢失 `shapeType`，多边形/OBB 操作会退化——A1 顺手修。
4. `removePolygonPoint` 对 3 点多边形静默拒绝；产品要求改为「删除后 <3 点时整体删除并提示」，需改语义。
5. 滚轮缩放范围实际为 5%~5000%（`qBound(0.05, …, 50)`），与旧文「1%~1600%」不一致；A2 统一为 **1%~1600%** 并给出映射说明。
6. 画布目前无右键消费逻辑，接入 `ContextMenu.qml`（`src/components/qml/ContextMenu.qml:6-38`，32 行通用 Menu）时需自行接线。

- Model 侧顶点增删改 API 齐备：`AnnotationModel.cpp:362`（改点）、`388`（插点）、`414`（删点）。
- 撤销快照已含多边形：`AnnotCanvasItem.cpp:1108-1112` 序列化 `polygonPoints`，`1137-1139` 恢复时走 `addPolygonAnnotation`。
- 读入缺陷：`YoloTxtReader.cpp:287` 要求 `parts.size() > 9`，三角形/四边形被丢；`detectFormat` L223 同样漏判。
- 剪贴板缺陷：`AnnotCanvasItem.cpp:1249/1295` 写死 `shapeType=0`。

#### A1.2 目标行为（用户可感知）

1. 选中多边形后每个顶点出现可抓取方块；拖拽顶点实时变形，松手完成一次可撤销操作。
2. 双击某条边，在该边中点插入新顶点；`Delete` 删除当前悬停/选中的顶点；顶点数将小于 3 时整体删除该多边形并弹 Toast 提示「顶点不足，已删除该多边形」。
3. 绘制中右键取消当前多边形（不入撤销栈）；Esc 同义。
4. 三角形、四边形、任意 N 边形保存后重开项目，顶点与类别完全一致；导出 txt 可被 labelme / Ultralytics 互转无坐标漂移。
5. 顶点命中半径随缩放反比（放大后更容易抓点，缩小后不易误触）。

#### A1.4 逐步实现（子步骤）

1. **修 `YoloTxtReader::parsePolygonLine` 与 `detectFormat`**
   - 判定改为 `parts.size() >= 7 && (parts.size() % 2) == 1`（1 + 2N，N≥3）。
   - `detectFormat` 同步：token 数 ≥7 且奇数 → Polygon；维持 5→HBB、9→OBB 优先（注意 9 个 token 同时满足 OBB 与「4 点多边形」的奇偶条件，**保持 OBB 优先**以兼容现网标签；混存场景由 `AnnotationService.setShapeType` 显式指定，不依赖探测）。
2. **`AnnotCanvasItem::HandlePosition` 增加顶点柄**
   - 新增 `VertexHandle` 语义不用扩枚举也可以：用 `m_editVertexIndex >= 0` 表达；推荐后者，避免 `computeHandlePositions` 分支污染。
3. **顶点命中**
   - 在 `hitTestAnnotation` 命中多边形后，再做顶点近距判定：遍历 `points`，比较画布距离 ≤ `HANDLE_HIT_RADIUS`；命中则进入 `m_editVertexIndex`。
   - 命中优先级：**顶点 > 边（双击插入）> 整体拖拽 > 背景**。
4. **拖拽顶点**
   - `mousePressEvent`：若 `m_editVertexIndex >= 0`，`pushUndo()` 后进入 `m_isDraggingVertex`。
   - `mouseMoveEvent`：`updatePolygonPoint(row, idx, imgX, imgY)`，坐标经 `canvasToImage` 并 clamp 到 [0,1]。
   - `mouseReleaseEvent`：复位拖拽态，`markDirty()` + `annotationModified`。
5. **双击插点**
   - `mouseDoubleClickEvent`（现 L760-777 只发 `editLabelRequested`）扩展：命中多边形边（线段距离 ≤ 命中半径）时 `addPolygonPoint(row, insertIndex, x, y)`；`insertIndex` 为该边终点下标。未命中边则维持现有改标签行为。
6. **删顶点**
   - `keyPressEvent` 的 `Delete` 分支：若 `m_editVertexIndex >= 0` 且当前多边形顶点数 > 3，`removePolygonPoint`；若顶点数 == 3，整体 `removeAnnotation(row)` 并 Toast；无顶点命中时走现有 `deleteSelected()`。
7. **绘制中右键取消**
   - `mousePressEvent` 增加 `Qt::RightButton` 分支：`m_isDrawingPolygon` 为真时清空点集并复位，不入撤销栈；否则（A2）交给右键菜单。
8. **剪贴板保形**
   - `copySelected / pasteClipboard / duplicateSelected` 中保留 `snap.shapeType` 与 `snap.polygonPoints`；`pasteClipboard`/`duplicateSelected` 按 `shapeType` 分发到 `addAnnotation / addOBBAnnotation / addPolygonAnnotation`。
9. **顶点吸附开关（可选，0.5 人日）**
   - `AppSettings` 增 `polygonSnapEnabled`（默认 true）；仅对首点闭合吸附生效，网格吸附本版不做。
10. **回归**
    - 扩展 `tests/test_labelio.cpp`、`tests/test_geometry.cpp`；跑 `test_labelio_atomic` 确认原子写未破坏。

#### A1.9 常见坑

- **9 token 歧义**：4 点多边形与 OBB 行都是 9 token。读入必须以 `AnnotationService.setShapeType` / 项目 `task_type` 为准，`detectFormat` 只作导入兜底；文档与代码注释都要写明。
- **撤销栈内存**：`UndoEntry` 全量快照含顶点表；50 步 × 数百标注 × 数十顶点仍可控，但不要把 QImage 塞进快照。
- **坐标空间混用**：绘制态点集存的是**画布坐标**（`m_polygonPoints`），提交时 `canvasToImage` 转换（L1325-1328）；编辑态 Model 存**归一化坐标**。拖拽顶点必须走 `canvasToImage`，否则放大后会漂。
- **Windows 头文件冲突**：`YoloTxtWriter.cpp:10-14` 用 `NOGDI` 规避 wingdi `Polygon` 与结构体 `Polygon` 撞名；新增包含 `<windows.h>` 的文件同样处理。

### 附录二：YOLO 多边形 / OBB 格式规范对照

统一约定：归一化坐标 [0,1]，小数点后 **6 位**（`YoloTxtWriter.cpp:114-119, 252-253`；`RotatedBox.cpp:90-98`），原子写入（tmp + `MoveFileExW`）。

| 形状 | 磁盘格式（每行） | token 数 | 内存结构 | 读写入口 | Ultralytics |
|------|------------------|----------|----------|----------|-------------|
| HBB | `class_id cx cy w h` | 5 | `AxisAlignedBox` | `write` / `read` | detect 标准格式 |
| OBB | `class_id x1 y1 x2 y2 x3 y3 x4 y4`（DOTA 四点，TL→TR→BR→BL） | 9 | `RotatedBox{cx,cy,w,h,angle°}` | `writeOBB` / `readOBB` | yolov8-obb 标准格式 |
| Polygon | `class_id x1 y1 x2 y2 … xn yn` | 1+2N（N≥3，奇数） | `Polygon{points[]}` | `writePolygon` / `readPolygon` | segment 的多边形部分（无 mask 时同形） |

补充规则：

1. **9 token 歧义**：OBB 与 4 点多边形同为 9 token。`detectFormat` 固定判 OBB；混存数据集必须由项目 `task_type` / `setShapeType` 显式指定解析器，禁止依赖嗅探。
2. **写出拒绝**：多边形 <3 点时 `formatPolygonLine` 返回空（`YoloTxtWriter.cpp:246-247`），整行不落盘；读入侧应对非法行跳过并计数（现状打 warning 日志，A1 增补 `dataset_samples.error_code` 落库）。
3. **角度往返**：`cx,cy,w,h,angle` ⇄ 四点存在 (w,h,angle) 与 (h,w,angle±90°) 等价类，测试用四点误差而非角度绝对误差。
4. **labelme 互转**：labelme 多边形为像素坐标 JSON，互转需乘/除图像宽高；抽检 20 条要求误差 < 1px（即归一化误差 < 1/max(w,h)）。
5. **分类 / 异常**：分类标签单行整型（或多标签空格分隔）；异常标签单行 `0|1`。与检测形状不混写同一 txt。

3. **第三档（8K+，可选）**：降采样金字塔（1/2、1/4 缩略）做导航小窗，主视口原图瓦片。
4. 禁止：为性能改写为 SceneGraph/OpenGL 路径（非目标）；禁止整图复制进撤销栈。

## 六、风险与依赖

| 风险/依赖 | 影响 | 应对 |
|-----------|------|------|
| 顶点命中与框选拖拽冲突 | 编辑体验差 | 优先级：顶点 > 边 > 整体 > 背景；命中半径缩放反比 |
| 9 token 格式歧义（OBB vs 4 点多边形） | 读错标签 | 解析以 task_type 显式指定；互转抽检 |
| 撤销快照内存 | 大图内存涨 | 只存标注结构；MAX_UNDO=50 保持 |
| ultralytics obb 版本行为 | 链路断 | 锁版本；失败信息进 `failure_info_json` |
| 复制上帧异尺寸失真 | 标注错位 | 归一化直拷 + 宽高比差提示；可一次撤销 |
| 辅助批量写库锁 | 卡顿 | 分批事务 + WAL；计时用例守门 |
| 快捷键与 Ctrl+1~8/F1 冲突 | 功能互抢 | 白名单 + 冲突检测 |
| GPU 机到位时间（A3/A4 验证） | 延期 | A1/A2/A5 可先在 CPU 机完成 |

7. 不在此版本做增量训练与主动学习 UI（v1.1.x 范围）。
