# 标炬（LabelTorch）产品蓝图

> 版本：2.0 | 更新日期：2026-05-18

---

## 一、产品定位

标炬是面向工业缺陷检测场景的**本地离线视觉数据治理与模型闭环平台**。

不是单纯的标注软件，也不是单纯的 YOLO 训练前端，而是覆盖**数据导入 → 标注修订 → 训练 → 评估 → 导出 → 发布**全链路的单机工作台。

### 核心价值主张

1. **训练效果最优** - 基于 Ultralytics 体系，支持多 YOLO 版本，确保训练质量
2. **标注与审核效率最优** - 辅助标注 + 人工审核闭环，大幅提升标注效率
3. **稳定性与可恢复性最优** - 任何操作可追溯、可回滚，绝不闪退
4. **本地交互性能最优** - C++ 前端 + GPU 加速渲染，工业级响应速度
5. **开箱即用** - 绿色免安装包，解压即用，无需配置环境

### 目标用户

- 单人使用的工业算法工程师
- Windows 平台，NVIDIA GPU 训练
- YOLO txt 格式数据集
- 需要频繁迭代模型版本

### 技术选型

| 层次 | 技术 | 职责 |
|------|------|------|
| 桌面前端 | Qt 6.11 + QML + C++17 | UI、标注引擎、几何渲染 |
| 训练后端 | Python 3.11 + Ultralytics | 训练、推理、导出 |
| 进程通信 | stdin/stdout JSON-RPC | 前后端解耦 |
| 元数据 | SQLite 3（WAL） | 项目、数据集、训练记录 |
| 构建 | CMake / Ninja / MSVC 2022 | C++ 编译 |
| 打包 | windeployqt + embed Python | 绿色免安装包 |
| CUDA | 12.1 | PyTorch 运行时 |

### v0.1.0 — MVP 核心训练闭环版

**目标**：用户能完成「创建项目 → 导入 YOLO 数据集 → 配置训练参数 → 训练模型 → 导出 pt/onnx」完整闭环。

**功能清单**：
1. 项目管理（创建/打开/删除项目）
2. YOLO txt 数据集导入（图片+标签目录选择、扫描匹配、异常报告）
3. 数据集浏览（缩略图网格、类别列表、统计面板）
4. 训练配置（模型选择 YOLOv8 n/s/m/l/x、img_size/batch/epochs/patience/device）
5. 训练执行（启动/停止、实时日志、进度展示、早停）
6. 训练结果（mAP50/mAP50-95/precision/recall）
7. 模型版本管理（版本列表、详情查看、标签管理）
8. 模型导出（pt 复制、ONNX 导出配置与验证）
9. 绿色安装包（解压即用，环境一体化）

**不包含**：标注功能、辅助标注、增量训练、多模型支持、OBB、数据快照

**验收标准**：
- [ ] 从零创建项目，导入 100+ 图片数据集，训练 5 epoch，导出 pt 和 onnx
- [ ] 训练过程中日志实时刷新，可随时停止
- [ ] 导出的 onnx 文件可通过 onnxruntime 加载验证
- [ ] 绿色包解压后无需任何环境配置即可使用

---

### v0.2.0 — 异常检测训练版

**目标**：在 YOLOv8 目标检测训练闭环基础上，新增异常检测（Anomaly Detection）模型训练与导出能力，覆盖工业缺陷检测中"只有正常样本"或"缺陷样本极少"的典型场景。

**功能清单**：
1. 异常检测任务类型支持（项目创建时可选"目标检测"或"异常检测"任务类型）
2. 异常检测模型适配器（基于 Ultralytics / Anomalib 体系，支持 PatchCore、PADIM、STFPM 等主流算法）
3. 异常检测训练配置（模型选择、img_size/batch/epochs、正常样本目录指定）
4. 异常检测训练执行（启动/停止、实时日志、进度展示）
5. 异常检测结果指标（image AUROC / pixel AUROC / F1 Score）
6. 异常检测模型版本管理（版本列表、详情查看、与训练任务关联）
7. 异常检测模型导出 ONNX（导出配置、ONNX 验证、推理速度基准测试）
8. 异常检测推理预览（单张图片推理、热力图叠加显示异常区域）
9. 训练适配器架构扩展（为后续多模型家族预留统一适配器接口）

**不包含**：标注功能、辅助标注、增量训练、OBB、主动学习

**验收标准**：
- [ ] 创建异常检测项目，导入正常样本数据集，训练 PatchCore 模型，导出 ONNX
- [ ] 训练过程中日志实时刷新，可随时停止
- [ ] 导出的 ONNX 文件可通过 onnxruntime 加载验证
- [ ] 单张图片推理可生成异常热力图并叠加显示
- [ ] 异常检测与目标检测共享项目管理和数据集浏览基础设施

### v1.0.0 — 标注引擎版

**目标**：高性能图像画布 + BBox 标注编辑能力。

**功能清单**：
1. 高性能图像画布（C++ QQuickItem，GPU 加速渲染）
2. 图像缩放（滚轮）、平移（空格+拖拽）
3. 样本列表侧边栏 + 前后切换（A/D 键）
4. BBox 创建（拖拽画框）
5. BBox 编辑（移动、缩放边角、删除）
6. 类别选择面板 + 快捷键（1-9 键）
7. 标签保存（YOLO txt 格式原子写回）
8. 标注状态提示（已保存/未保存）
9. 快捷键体系完整实现

**验收标准**：
- [ ] 4000×3000 图片缩放平移流畅（≤16ms 帧时间）
- [ ] 画框→保存→重载，框坐标一致
- [ ] 连续切换 100 张样本无卡顿无崩溃

### v1.1.0 — 辅助标注版

5. 批量确认（按置信度阈值一键确认高置信框）
6. 确认后的框写回标签文件
7. 审核状态统计

## 五、质量红线

1. **零闪退** - 任何异常必须被捕获并优雅处理，绝不允许程序崩溃
2. **训练不中断** - 训练过程中主界面必须保持响应，Python 后端异常不影响前端
3. **数据不丢失** - 所有写操作原子化，异常中断后数据可恢复
4. **GPU 兼容** - 支持 30/40/50 系列 NVIDIA 显卡
5. **性能达标** - 4000×3000 图片标注帧时间 ≤16ms，数据集导入 1000 张 ≤10s

## 六、发布规范

1. 每个版本发布 git tag（格式：v{major}.{minor}.{patch}）
2. 每个版本发布 GitHub/Gitee Release
3. Release 包含：可执行安装包/绿色包 + CHANGELOG + 源码归档
4. 绿色包格式：`LabelTorch-v{version}-cuda12.1-win64.7z`
5. 安装包格式：`LabelTorch-v{version}-setup.exe`
