# 标炬（LabelTorch）产品蓝图与版本规划

> 版本：5.0 | 更新日期：2026-06-08
> 状态：当前有效蓝图

---

## 一、产品定位

标炬（LabelTorch）是面向工业缺陷检测场景的本地离线桌面平台，目标是把数据导入、数据治理、训练、测试、导出和后续标注协作收敛到一个统一工作台中。

当前产品路线遵循两条核心原则：

1. 先保证训练闭环稳定可用
2. 再逐步建设高保真工业级 UI 和完整标注生态

---

## 二、当前阶段总目标

当前阶段采用 `MVP+` 路线，目标由两部分组成。

### 2.1 业务闭环目标

必须优先打通并稳定以下链路：

1. 项目创建与打开
2. 数据集导入
3. 数据集扫描与异常提示
4. 数据划分或快照生成
5. 训练参数配置
6. `YOLOv8` 目标检测训练
7. 异常检测训练
8. `pt` 导出
9. `onnx` 导出
10. 导出后验证

### 2.2 UI 目标

UI 采用高保真复刻路线，最高参考源为：

- `reference/Dihuge DLTools/gemini-code-1780391652706.html`

该参考源决定当前阶段的页面布局、视觉语言、组件层级、按钮风格、状态反馈和主要弹窗结构。

---

## 三、系统功能版图

平台当前按 7 个主页面组织：

1. 项目
2. 数据集
3. 标注
4. 检查
5. 训练
6. 测试
7. 导出

整体框架采用：

1. 顶部导航栏
2. 顶部过滤栏
3. 主内容区
4. 可调分栏面板
5. 底部日志或状态区

### 3.1 项目

负责项目创建、打开、最近项目访问和项目级默认配置。

### 3.2 数据集

负责导入、扫描、样本浏览、样本属性、Tag 管理和后续划分准备。

### 3.3 标注

当前阶段以高保真 UI 骨架和结构预留为主，为后续 HBB、OBB、多边形和辅助标注能力提供承载空间。

### 3.4 检查

负责问题样本浏览、筛查视图和后续质检流程的 UI 承载。

### 3.5 训练

当前阶段是主战场，负责：

1. 数据集快照选择
2. 网络结构选择
3. 训练参数配置
4. 数据增强配置
5. 训练状态展示
6. 实时指标展示

### 3.6 测试

当前阶段以评估视图结构和后续结果分析入口为主，逐步接入真实评估链路。

### 3.7 导出

当前阶段必须承载真实的导出与验证能力，是核心闭环一部分。

## 四、当前阶段范围边界

### 4.1 当前阶段必须完成

1. `YOLOv8 detect` 真正可训练
2. 异常检测真正可训练
3. `pt` 与 `onnx` 真正可导出并验证
4. 支持 `NVIDIA 30/40/50` 和 `CPU-only` 训练路径
5. UI 达到高保真空壳复刻标准

### 4.2 当前阶段允许预留但不作为主验收项

1. OBB 完整训练闭环
2. 分类完整训练闭环
3. 完整标注引擎交付
4. 辅助标注正式版
5. 增量训练完整产品化
6. TensorRT、TFLite、Engine 等完整导出闭环
7. Ubuntu 交付级兼容
8. 匹配页面

## 五、版本路线图

### v0.1.x：MVP+ 稳定化阶段

交付重点：

1. 项目、数据集、训练、导出主链路稳定
2. `YOLOv8 detect + anomaly` 可用
3. `pt + onnx` 导出与验证可用
4. 高保真 UI 骨架完成

### v0.2.x：UI 接线与测试补强阶段

交付重点：

1. UI 与真实数据流打通
2. 测试页和导出页补强
3. 全局状态、日志、任务中心增强

### v1.0.x：标注引擎阶段

交付重点：

1. HBB 标注
2. OBB 标注
3. 多边形标注
4. 撤销重做与原子写回

### v1.1.x：辅助标注与增量训练阶段

交付重点：

1. 历史模型辅助标注
2. 批量审核
3. 增量训练入口
4. 模型血缘链增强

### v2.x：数据治理与全生命周期阶段

交付重点：

1. 快照体系强化
2. 主动学习
3. 模型版本治理
4. 多模型家族扩展

---

## 六、关键设计边界

1. Qt/C++ 主进程负责 UI、本地状态、数据库和 Python 子进程管理
2. Python 后端负责训练、导出、验证、推理等计算任务
3. 训练必须基于不可变快照
4. 模型版本必须可追溯到训练运行和快照
5. 导出产物必须经过验证
6. 软件必须支持离线使用和 CPU 降级路径

---

## 七、执行原则

1. 先稳定闭环，再扩展页面功能
2. 先统一组件和设计系统，再复刻页面
3. 先复刻 UI 外壳，再接真实数据
4. 每个阶段都按里程碑验收
5. 当前阶段执行时，以 `docs/执行总计划-LabelTorchV-MVP+.md` 为总控文档
