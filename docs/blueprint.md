# 标炬（LabelTorch）产品蓝图与版本规划

> 版本：3.0 | 更新日期：2026-05-30
> 状态：设计重构与规划阶段

---

## 一、产品定位与愿景

**标炬（LabelTorch）** 是一款面向工业缺陷检测与计算机视觉（CV）场景的**本地化、一站式视觉数据治理与模型训练评估平台**。

它旨在打破传统视觉开发流程中“数据标注（LabelImg/LabelMe）”、“格式转换（脚本开发）”、“模型配置与训练（Ultralytics 命令行/源码修改）”、“指标评估（TensorBoard）”与“部署导出（手动转换）”之间的割裂状态，为算法工程师与质量检测人员提供**端到端、零代码配置、全生命周期管理**的桌面工作台。

### 1. 核心价值主张
* **零门槛闭环**：导入 → 标注 → 检查 → 训练 → 测试 → 导出，一键式流转。
* **本地化优先**：充分挖掘本地 GPU 显卡算力，数据不出网，保障工业数据安全性。
* **开箱即用**：集成内置的 Python 运行时环境，消除繁琐的 CUDA、PyTorch 及依赖库配置。
* **卓越交互**：现代暗黑工业风界面，丝滑的 Canvas 标注画布与直观的数据看板。

## 二、系统功能版图

本平台围绕 CV 模型生命周期，设计了 7 大核心模块，整体采用**顶部全局导航 + 左中右三栏布局**的桌面端风格：

```
┌────────────────────────────────────────────────────────────────────────┐
│                              顶部全局导航栏                             │
│  [项目管理]  [数据集管理]  [数据标注]  [数据检查]  [模型训练]  [模型测试]  [模型导出]│
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                             主内容展示区域                             │
│                      (左中右三栏式/网格画廊/核心画布)                     │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│                             底部实时日志与状态                         │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 项目管理 (Project)
* **新建项目 (New Project)**：输入项目名称、描述，选择存储路径（本地绝对路径），指定默认任务类型（目标检测/旋转框检测/分类/异常检测）。
* **打开项目 (Open Project)**：载入已有的项目元数据与数据库记录。
* **最近使用项列表**：展示项目名称、描述、物理路径、上次修改时间。

### 2. 数据集管理 (Dataset)
* **数据集导入**：支持 YOLO 格式、COCO 格式和分类文件夹导入，自动扫描匹配图片-标签对并报告异常（漏标、格式错误等）。
* **图库浏览器 (Gallery)**：流式加载缩略图网格，支持按标签、Tag（标签属性）、文本搜索等多重过滤。
* **左侧属性栏**：支持图库库区管理、数据集列表可见性控制、单张图像属性展示（名称、路径、分辨率、标签实例、类别分布）。

### 3. 数据标注 (Annotation)
* **高性能画布**：基于 Fabric.js / Konva.js 构建，支持滚轮缩放、空格拖拽平移、标注实体交互。
* **标注工具箱**：支持矩形（HBB）、旋转矩形（OBB）、多边形（Polygon）、魔棒/笔刷分割工具，明暗度与对比度实时调节。
* **双侧面板**：左侧为图像快速切换列表与进度条；右侧为当前图像的标注实例列表（类别、坐标、面积）与文件目录。

### 4. 数据检查 (Inspection)
* **智能质检**：专门的过滤机制，帮助用户快速筛选出“未标注图像”、“异常尺寸图像”、“标签冲突图像”。
* **程度图像模式**：针对工业质检中缺陷程度的二次确认（如标注缺陷严重程度级别）。

### 5. 模型训练 (Training)
* **超参数配置**：支持 Epochs、Batch Size、Optimizer、Learning Rate、设备选择（CPU/GPU指定）、保存周期等。
* **数据增强策略**：平移、旋转、缩放、翻转、明暗色调变化的可视化控制。
* **运行管理**：支持一键启动训练、早停（Patience）、训练日志实时流式刷新、Epoch 级指标可视化展示。

### 6. 模型测试 (Testing)
* **多维度评估**：在指定测试集上评估模型，配置 IoU 阈值、置信度阈值。
* **评估看板**：自动生成 Precision-Recall (PR) 曲线，提供精确率、召回率、F1 分数的直观仪表盘。

### 7. 模型导出 (Export)
* **多格式支持**：将模型权重导出为 `.pt`、`.onnx`、`TensorRT (Engine)` 等格式。
* **导出验证**：导出后自动运行 ONNX Runtime 验证包，确保模型文件完整可用。

## 三、版本迭代路线图

为了降低开发风险，确保每阶段产物均可独立运行与验证，产品采用**“核心闭环先行，标注引擎跟进，辅助功能叠加”**的迭代路径：

```
v0.1.0 (MVP)         v1.0.0               v1.1.0               v2.0.0+
核心训练闭环 ───► 高性能标注引擎 ───► 辅助标注与审核 ───► 增量训练与数据治理
(导入/训练/导出)    (Fabric.js画布)       (模型推理候选框)      (版本追踪/智能纠错)
```

| 版本号 | 版本定位 | 核心交付功能 | 不包含功能 | 验收标准 |
| :--- | :--- | :--- | :--- | :--- |
| **v0.1.0 (MVP)** | 核心训练闭环版 | 项目管理、YOLO数据集导入、模型配置与训练、日志与指标、模型导出为pt/onnx、绿色免安装依赖包。 | 数据画布、在线标注、异常检测任务、辅助标注。 | 导入100张图片，配置YOLOv8，启动训练5个epoch，成功导出并验证onnx文件，全流程不闪退。 |
| **v0.2.0** | 异常检测专版 | 支持无监督/半监督异常检测（PatchCore/PADIM等），支持热力图推理预览与异常程度确认。 | 目标检测增量训练、高级标注。 | 导入正常样本，配置异常检测网络，训练并导出，使用单张测试图能正确渲染热力图。 |
| **v1.0.0** | 高性能标注引擎版 | 引入 Fabric.js/Konva.js 标注画布，支持 HBB 矩形框、OBB 旋转框、分类打标，快捷键系统。 | 多边形分割、智能辅助标注。 | 画布缩放平移无卡顿，创建/删除/拖动选框准确写回本地 YOLO 格式文本，支持撤销/重做。 |
| **v1.1.0** | 智能辅助标注版 | 引入历史模型推理接口，对未标注数据集进行预标注（自动生成虚线候选框），人工一键审核确认。 | 增量模型谱系图、高精度主动学习筛选。 | 启动辅助标注，1秒内对单张图生成候选框，支持高置信度批量确认与写回。 |
| **v2.0.0+** | 数据治理与谱系追踪 | 数据快照（Snapshot）管理，版本变更对比，增量训练（继续训练与迁移学习），类别体系变更追踪。 | - | 完整重构并实现企业级的多模型家族（YOLOv5-v11）全生命周期闭环。 |

## 四、核心系统设计边界

### 1. 职责边界
* **平台端（前端壳体）**：负责 UI 交互、本地数据库（SQLite）状态同步、画布渲染、本地文件系统操作、以及向 Python 后端发送 IPC 控制指令。
* **计算端（Python 后端）**：负责 PyTorch 训练、数据划分、Ultralytics 接口适配、推理计算、ONNX 转换及验证。**平台端通过 stdin/stdout JSON-RPC 与计算端进行异步消息交互。**

### 2. 状态边界
* 训练与标注基于 **不可变快照 (Snapshot)** 进行隔离。一旦训练任务启动，其引用的数据集配置将自动生成不可变数据清单，避免标注与训练的并发冲突。

### 3. 环境边界
* 软件必须提供**绿色免安装版本**，集成嵌入式 Python 解释器和必要的 CUDA/PyTorch 预编译库。主程序在启动时应执行环境自检，如果 CUDA 不可用，提供 CPU 降级提示。
